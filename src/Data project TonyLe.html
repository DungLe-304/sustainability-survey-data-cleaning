Data Cleaning Steps

(a) Recode Gender as a Factor with 3 Short Categories

# The raw data contains three character values for Gender.
# We recode them to short labels and convert to a factor so that
# R treats Gender as a categorical variable (not free text) in
# all plots and models.

df <- df %>%
  mutate(
    Gender = case_when(
      Gender == "Female"                   ~ "Female",  # keep as-is
      Gender == "Male"                     ~ "Male",    # keep as-is
      Gender == "Other/ prefer not to say" ~ "Other",  # shorten the label
      TRUE                                 ~ NA_character_  # any unexpected value -> NA
    ),
    # Wrap the recoded character column in factor() with explicit levels.
    # This controls the display order in every table and graph.
    Gender = factor(Gender, levels = c("Female", "Male", "Other"))
  )

(b) Recode Grade Level to Numeric Values 1–5

# Step 1: trimws() strips any leading or trailing whitespace from the
# Grade column. Without this, "First-year " (with a hidden trailing space)
# would not match "First-year" in case_when and would silently become NA.
# Step 2: case_when maps each year-description to an integer 1-5 so that
# graphs automatically display grade levels in the correct chronological order.

df <- df %>%
  mutate(
    Grade = trimws(Grade),   # remove hidden whitespace (e.g. "First-year ")
    Grade = case_when(
      Grade == "First-year"                   ~ 1,
      Grade == "Second-year"                  ~ 2,
      Grade == "Third-year"                   ~ 3,
      Grade == "Fourth-year"                  ~ 4,
      Grade == "more than 4 years at Truman"  ~ 5,
      TRUE                                    ~ NA_real_  # safety net for unexpected values
    )
  )

# Verify: should show counts for integers 1-5, no NAs
df %>% count(Grade)

1     1 55
2     2 40
3     3 45
4     4 40
5     5  2

Explanation: The homework warns that some grade-level values contain extra spaces. trimws() solves this in one step rather than having to hard-code every possible spacing variant inside case_when. The result is numeric so R can sort and scale grade levels correctly on plot axes.

(c) Split School Column into School1, School2, and School3

# The School column holds one, two, or three school abbreviations
# separated by single spaces (e.g. "HSE SAM BUS").
# separate() splits the column on whitespace into up to three pieces.
#   extra = "drop"  -> silently discard any token beyond the 3rd
#   fill  = "right" -> pad with NA on the right for students with
#                      fewer than 3 schools listed
# Note: we pass col as a quoted string "School" to avoid the
# "object 'School' not found" error that occurs in some R versions
# when the bare column name is used.

df <- df %>%
  separate(
    col   = "School",
    into  = c("School1", "School2", "School3"),
    sep   = " ",
    extra = "drop",   # ignore any extra tokens beyond 3
    fill  = "right"   # fill unused columns with NA
  )

(d) Create the SAM Binary Indicator Column

# Create a column named SAM that equals 1 if the student
# listed the School of Science and Mathematics in ANY of the three school
# columns, and 0 otherwise.
#
# if_else() evaluates the logical condition for each row:
#   - TRUE  -> 1L  (the student listed SAM)
#   - FALSE -> 0L  (the student did not list SAM)
#   - missing = 0L -> if a comparison involves NA (e.g. School2 is NA),
#                     treat it as "not SAM" rather than producing NA

df <- df %>%
  mutate(
    SAM = if_else(
      School1 == "SAM" | School2 == "SAM" | School3 == "SAM",
      true    = 1L,
      false   = 0L,
      missing = 0L   # NA comparisons treated as FALSE (not listed = not SAM)
    )
  )

2   1  50

(g) Recode Tuition Increase as an Ordered Factor

# The Increase_rate column is currently a character variable.
# By default R would display these values in alphabetical order, which is
# meaningless for this ordinal variable ("$1-$10" before "Not willing at all"
# alphabetically, for example).
#
# Solution: convert to an ORDERED factor with the five levels listed in the
# exact sequence specified in the assignment. R will then display and sort
# these values correctly in every plot and table automatically.
#
# IMPORTANT: the level labels below match the EXACT capitalisation found in
# the raw data — do NOT change them. Mismatched capitalisation would cause
# all values to become NA.

# Show current (alphabetical / arbitrary) ordering
cat("--- Before recoding ---\n")

# Define the correct ordinal sequence (low to high willingness)
tuition_levels <- c(
  "Not willing at all",   # least willing
  "$1-$10",
  "$11-$20",
  "$21-$30",
  "anything above $30"    # most willing
)

df <- df %>%
  mutate(
    Increase_rate = factor(
      Increase_rate,
      levels  = tuition_levels,
      ordered = TRUE   # ordered = TRUE marks this as an ordinal variable
    )
  )

)

# Step 1: Compute mean willingness score per school so we can order schools
#         from least to most willing on the x-axis.
#         as.integer() converts the ordered factor levels to 1-5 numerically.
school_order <- df %>%
  filter(!is.na(School1), !is.na(Increase_rate)) %>%
  mutate(will_num = as.integer(Increase_rate)) %>%
  group_by(School1) %>%
  summarise(mean_will = mean(will_num), .groups = "drop") %>%
  arrange(mean_will) %>%
  mutate(School_Full = recode(School1, !!!school_labels))

# Step 2: Build the percentage table for the stacked bars
plot_df <- df %>%
  filter(!is.na(School1), !is.na(Increase_rate)) %>%
  mutate(School_Full = recode(School1, !!!school_labels)) %>%
  count(School_Full, Increase_rate) %>%
  group_by(School_Full) %>%
  mutate(pct = n / sum(n) * 100) %>%   # convert counts to percentages within each school
  ungroup() %>%
  # Apply the school ordering determined in Step 1
  mutate(School_Full = factor(School_Full,
                              levels = school_order$School_Full))

# Step 3: Draw the stacked bar chart
ggplot(plot_df,
       aes(x    = School_Full,
           y    = pct,

Answer to Q3b:

  • The school with the least willingness to increase tuition is Business (mean score = 1.83, 30.4% “Not willing at all”) — appearing at the top of the table above since it is sorted low-to-high.
  • The school with the most willingness is Science & Math (mean score = 2.62, only 17.0% “Not willing at all”) — appearing at the bottom of the table.
